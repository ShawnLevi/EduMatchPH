How it works

  1. Add applicants

    Type them in one by one, or import a .csv or .xlsx file and preview it first.

  2. Run screening

    Each applicant is checked against the program’s rules, with a clear met or not met for every one.

  3. Rank and shortlist

    Eligible applicants are ranked into a shortlist and a waitlist, and you can open the reasoning behind each place.
